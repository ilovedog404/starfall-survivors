星隕倖存者 Beta0.6.2
======================

版本定位
--------
強化 Web 長局穩定性，避免未拾取物件與短命特效無限制累積。

新增與調整
----------
1. 畫面最多保留 480 個經驗碎片，超額經驗會合併到既有碎片且不遺失數值。
2. 畫面最多保留 24 個修復核心，超額補給會合併回復量。
3. 同時存在的短命特效限制為 320 個，優先保留最新回饋。
4. 既有異變體上限維持 650 個，新增自動化驗證。
5. 新增 700 次擊殺與 650 敵人的高負載測試場景。
6. GitHub Pages 與 Release 發布前會額外執行高負載測試。

測試結果
--------
- Godot 版本：4.7.2.stable.steam
- 自動煙霧測試：通過
- 246 秒加速完整局模擬：通過（三個波次、使徒生成與結算正常）
- 高負載上限測試：通過（650 敵人、480 碎片、24 核心、320 特效；1190 經驗完整保留）
- 發布流程會核對測試通過標記，避免 Godot 載入錯誤造成假陽性
- Web 匯出：通過
- Chromium 瀏覽器實測：角色選擇、Beta0.6.2 版本字樣與繁體中文顯示正常

與前一版差異
--------------
Beta0.6.1 新增傷害來源統計；本版加入長局資源上限與 CI 高負載防線。
