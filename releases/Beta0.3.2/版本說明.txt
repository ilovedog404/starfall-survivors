星隕倖存者 Beta0.3.2
======================

版本定位
--------
補齊滑鼠操作與自動發布前的品質防線。

新增內容
--------
1. Esc 暫停改為完整選單。
2. 暫停選單提供「繼續戰鬥」、「重新開始本角色」與「返回角色選擇」。
3. 鍵盤仍可用 Esc 快速暫停與繼續。
4. GitHub Pages 部署前會自動執行煙霧測試與 246 秒完整局模擬。
5. GitHub Beta Release 建置前同樣會先執行兩套測試。
6. 任一核心測試失敗時，不會發布該次線上版本或 Release。

測試結果
--------
- Godot 版本：4.7.2.stable.steam
- 自動煙霧測試：通過
- 已驗證：暫停選單恢復、建構、敵人波次、戰技與結算流程
- 246 秒加速完整局模擬：通過（三個波次、使徒生成與結算正常）
- Web 匯出：通過
- Chromium 瀏覽器實測：開始畫面、版本字樣與繁體中文顯示正常

已知問題
--------
1. 暫停選單尚未加入音量設定。
2. GitHub 雲端測試會讓每次部署增加約一分鐘。
3. 首次載入 Web 版仍需下載約 19 MB 壓縮資料。

與前一版差異
--------------
Beta0.3.1 增加敵人波次；本版強化滑鼠操作與自動發布驗證。
