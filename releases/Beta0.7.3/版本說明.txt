星隕倖存者 Beta0.7.3
======================

版本定位
--------
改善桌面瀏覽器鍵盤操作，避免瀏覽器攔截按鍵時無法開啟遊戲功能。

新增與調整
----------
1. 新增 B 作為「目前建構」的替代鍵，Tab 仍可使用。
2. 新增 P 作為暫停／繼續的替代鍵，Esc 仍可使用。
3. 戰鬥 HUD、建構畫面與暫停畫面提示同步顯示替代按鍵。
4. README 更新為目前實際內容：四名角色、三種武器、進化、異變體種類、波次與傷害結算。
5. README 補齊空白鍵、B／Tab、Esc／P、數字鍵與 R 的完整操作。
6. 自動測試會驗證 B 與 P 確實註冊到 Godot 輸入映射。

測試結果
--------
- Godot 版本：4.7.2.stable.steam
- 自動煙霧測試：通過（B／P 輸入映射及既有戰鬥流程）
- 246 秒加速完整局模擬：通過（三個波次、使徒生成與結算正常）
- 高負載上限測試：通過（650 敵人及掉落／特效上限正常）
- Web 匯出：通過
- 獨立 Chromium 瀏覽器實測：B 可開啟建構面板、P 可開啟暫停選單，畫面提示與版本字樣正常

與前一版差異
--------------
Beta0.7.2 為投射型異變體加入預警；本版強化瀏覽器鍵盤相容性並修正文檔。
