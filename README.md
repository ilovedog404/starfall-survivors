# 星隕倖存者

《星隕計畫 Ark Re:Code》的非官方生存 Roguelite 同人原型。首個版本以瀏覽器、鍵盤滑鼠與低複雜度的自動戰鬥為目標。

**[立即遊玩最新 Web 版](https://ilovedog404.github.io/starfall-survivors/)**

## 目前可玩內容

- 四名可玩角色：埃帕蒂、璐茜婭、克萊兒、菈法瑞・零度・諾恩。
- 每名角色都有不同的起始環域效果、被動特性與空白鍵主動戰技。
- 三種自動武器：角色專屬環域、星針、脈衝雷暴；可進化「崩星護界」與「追星蜂群」。
- 追逐、奔襲、投射、重裝與精英異變體；危險攻擊具方向預警。
- 星源碎片、三種武器與七種被動的升級三選一、一次免費重抽、精英修復核心與 Tab／B 建構總覽。
- 五分鐘完整流程；三次定時波次，測試使徒於第四分鐘降臨。
- 暫停選單、分來源傷害結算、重新開始與角色重選。

## 執行

以 Steam 版 Godot 4.7.2 開啟本資料夾，執行主場景即可。Web 匯出預設名稱為 `Web`。每個 `Beta…` 標籤會自動建立 GitHub 預發布版本及可下載的 Web 壓縮檔；`main` 分支則自動更新線上試玩頁。

## 操作

- WASD／方向鍵：移動
- 空白鍵：角色主動戰技
- B／Tab：查看目前建構（瀏覽器攔截 Tab 時請使用 B）
- Esc／P：暫停或繼續
- 1／2／3：選擇升級；R：重新抽取
- 滑鼠左鍵：選角、升級、暫停選單與結算按鈕
