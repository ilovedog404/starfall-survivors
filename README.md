# 星隕倖存者

《星隕計畫 Ark Re:Code》的非官方生存 Roguelite 同人原型。目前正改造成以 2D billboard 角色、2.5D 荒原探索與自動戰鬥為核心的瀏覽器遊戲。

**[立即遊玩最新 Web 版](https://ilovedog404.github.io/starfall-survivors/)**

## 目前可玩內容

- 改版首位可玩角色為埃帕蒂；先遣小屋使用獨立場景背景，角色與選角介面由遊戲分層繪製。
- 埃帕蒂會自動施放疾風短刃，並能進化為以青綠星源光效暫代二階新皮的裂空刃舞。
- 十組基礎武器為疾風短刃、星針、磁軌飛刃、離子戰斧、折返星環、軌道刃陣、隕炎彈、等離子場、冷媒污染區與折射游標。
- 新增程式生成的星蝕荒原，以及狼型、甲蟲型、機械型異變體 billboard 美術。
- 追逐、奔襲、投射、重裝、護衛、分裂、污染型異變體，以及迅捷／護盾／爆裂精英詞綴；危險攻擊具方向預警。
- 星源碎片、每局最多六件武器與六種被動的升級三選一、一次免費重抽、精英修復核心、進化核心與 Tab／B 建構總覽。
- 九種被動可支援生命、機動、防禦、冷卻、範圍、持續修復與投射武器等不同建構方向。
- 五分鐘完整流程；三次定時波次，測試使徒於第四分鐘降臨。
- 使徒阿努巴拉克具兩階段戰鬥；半血後會切換扇形彈幕、衝撞與地面危險區，攻擊前皆有預警。
- 暫停選單、分來源傷害結算、重新開始與角色重選。

## 執行

以 Steam 版 Godot 4.7.2 開啟本資料夾，執行主場景即可。Web 匯出預設名稱為 `Web`。每個 `Beta…` 標籤會自動建立 GitHub 預發布版本及可下載的 Web 壓縮檔；`main` 分支則自動更新線上試玩頁。

## 操作

- WASD／方向鍵：移動
- B／Tab：查看目前建構（瀏覽器攔截 Tab 時請使用 B）
- Esc／P：暫停或繼續
- 1／2／3：選擇升級；R：重新抽取
- 滑鼠左鍵：選角、升級、暫停選單與結算按鈕
- 左側 GM 測試面板：切換 3 倍速、立即升級、增加重骰次數、一次啟用十組武器
